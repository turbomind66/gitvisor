# GitVisor

本地自建的「类 GitHub」Git 可视化管理界面。零第三方依赖，仅用 Node.js 内置模块 + 已安装的 git。
所有操作只在 `127.0.0.1` 本地进行，**不联网、不推送任何远程**。

## 功能
- 左侧自动扫描配置的仓库，列出分支并标注状态（当前 / 主干 / 领先 N / 落后 N / 已合并）
- 审查分支：查看提交列表 + 行级 diff
- 合并分支：`git merge --no-ff`（合并前检查工作区干净，冲突自动 `merge --abort`）
- 删除分支
- 回退：`git revert` 撤销某次合并 / 某次提交（不丢历史，可反复撤销/重做）
- 查看主干提交历史

## 运行
需要 Node.js 与 git（已加入 PATH）。

```
node server.js
```

或直接双击 `start.bat`（已处理中文编码）。默认监听 `http://127.0.0.1:4590`。

## 配置
复制 `config.example.json` 为 `config.json` 并按需修改：

- `port` / `host`：监听端口与地址（默认 `127.0.0.1:4590`）
- `scanDirs`：要扫描的目录（相对或绝对），会递归查找其中的 git 仓库
- `extraRepos`：直接指定的仓库路径列表

`config.json` 已被 `.gitignore` 忽略，不会进入版本库。若 `config.json` 不存在，程序会自动回退使用 `config.example.json`。

## 适用场景
多 agent 本地协作：每个 agent 各自建分支、各自提交，由你在界面上审查、确认合并哪些改动。

## 安全说明
- 仅绑定本地回环地址，不对外暴露。
- 回退使用 `git revert`（生成反向提交），不重写历史、不丢数据，比 `reset --hard` 更安全。
- 合并 / 回退前都会检查工作区是否干净，冲突会自动中止还原。
